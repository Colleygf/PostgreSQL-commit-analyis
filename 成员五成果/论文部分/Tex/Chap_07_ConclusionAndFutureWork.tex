\chapter{结论与未来工作}\label{chap:conclusion}

\section{主要研究结论}
本文围绕 PostgreSQL Bug 修复演化给出系统研究：构建数据集与识别规则，提炼静态修复模式，完成动态复现，并通过 Z3 提供修复正确性验证。

\section{工程实践建议}
建议在工程流程中落地三项实践：
\begin{itemize}
    \item 将修复识别与模块风险统计纳入例行质量看板；
    \item 将动态回归与关键路径日志作为发布前强制检查；
    \item 对高风险逻辑引入轻量级形式化验证。
\end{itemize}

\section{后续工作（自动检测、自动修复、CI 集成）}
后续可从三方面扩展：基于历史修复模式训练自动检测器；探索面向条件与错误路径的自动修复策略；将静态、动态和形式化检查进一步集成到 CI 流水线。
